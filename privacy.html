Introduction

Lyra (“Lyra”, “the Bot”, “we”) is a music bot for Discord. This policy explains what data Lyra collects, how it is used, and what choices you have. By using Lyra you agree to this policy.

Data we collect

Lyra works through slash and prefix commands and collects only what it needs to run them:

  • Discord User IDs, Server (Guild) IDs, Channel IDs, Voice Channel IDs and Role IDs.
  • Server settings configured by admins, such as volume, loop mode, DJ role and 24/7 mode.
  • The music queue and playback state of each server while the bot is active.
  • Song names, links or search queries you enter in commands.
  • Content you choose to save: liked songs and playlists (playlist names and the song titles or links in them), linked to your Discord User ID.
  • Feature settings such as audio filters and the list of users who have been given no-prefix access (User IDs only).
  • Basic error logs: command name, error message and timestamp.

Message content. Lyra supports prefix commands (for example !play) as well as slash commands. To detect prefix commands, Lyra uses the Message Content intent and checks each message only to see whether it starts with the server’s command prefix. For users who have been given no-prefix access, Lyra checks whether the message begins with a command name instead. Messages that are not commands are ignored immediately. Message content is not stored, logged or shared. Only the text of a command (such as a song name) is used to run that command.

Member counts. Lyra shows the total number of servers and members using the member count that Discord provides for each server. Lyra does not use the Server Members or Presence privileged intents, does not collect member lists or online status, and never records or listens to voice conversations.

How we use data

Data is used only to provide and improve Lyra’s features: playing music, managing queues, saving your liked songs and playlists, and saving server settings. We do not sell data, use it for advertising, or use it to train AI or machine-learning models.

Third-party services

To find and stream music, search queries or links you provide may be sent to third-party music sources and APIs. Our hosting and database provider also processes the data above on our behalf. These services have their own privacy policies.

Storage and security

Data is stored on secured servers and access is limited to the developer. We use reasonable measures to protect it, but no system is 100% secure.

Data retention

Server settings are kept while Lyra is in your server. If Lyra is removed, that server’s data is deleted within 30 days. Error logs are kept for up to 30 days. Queue data is temporary and cleared when playback ends or the bot leaves voice. Liked songs, playlists and no-prefix settings are kept until you delete them with the bot’s commands or ask us to delete them.

Deletion requests

You can ask us to delete your data or your server’s data at any time using the contact details below. We process requests within 14 days.

Children

Lyra is not intended for anyone under the minimum age required by Discord (13, or higher in your country). We do not knowingly collect data from children below that age.

Changes to this policy
